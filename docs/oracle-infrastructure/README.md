# Oracle Cloud 인프라 메모

마지막 정리: 2026-10-17

출석체크 앱 서버를 OCI에 올리기 위한 계정·비용·운영 결정 사항을 모아 둔다. 카드 번호, CVN, 비밀번호, 개인 키 등 비밀 정보는 이 문서에 저장하지 않는다.

## 현재 진행 상황

- OCI 결제 수단 검증을 통과함.
- 사용자가 계정 업그레이드 요청을 제출했고 화면에 `요청이 성공적으로 제출되었습니다. 자세한 내용은 사용량 기준 섹션을 확인하십시오.`가 표시됨.
- 이 메시지만으로 PAYG 전환 완료를 확정할 수는 없음. `청구 및 비용 관리 → 결제 업그레이드 및 관리`에서 계정 유형/상태가 유료 또는 사용량 기준으로 변경됐는지 확인할 것.
- 전환 완료 확인 전에는 유료 인스턴스를 만들지 말 것.
- 계정 화면에 등록된 주소는 연수구 주소로 표시됨. 광교로 주소를 바꾸려는 경우 결제 주소/계정 주소가 서로 다를 수 있으므로, Oracle 계정에 실제로 등록된 주소 상태를 먼저 확인할 것. 화면 안내상 개인 계정 주소 변경은 제한될 수 있음.

## 서버 계획

- 용도: 출석체크 앱의 백엔드/서버 운영.
- 목표 예산: 월 약 30,000원. 다만 사용량 기준 계정은 지출 상한을 자동으로 강제하는 기능이 아님.
- 우선 검토 인스턴스: VM.Standard.A1.Flex, 시작 사양 2 OCPU / 12 GB. 실제 앱 요구량에 맞춰 정하고, 필요하면 작게 시작해 조정할 것.
- 한국 사용자 대상이면 한국 리전을 우선 검토하고, 앱을 배포한 뒤 실제 사용자 경로에서 응답 시간을 측정할 것. 콘솔 UI 속도와 배포 앱의 서버 응답 속도는 별개임.
- 예산/비용 알림은 설정하되, 알림만으로 과금이 정지되지는 않는다고 가정할 것. 비용 분석을 정기적으로 확인하고, 쓰지 않는 인스턴스·디스크·백업·유료 이미지가 남지 않도록 관리할 것.

## A1 무료 한도와 비용 계산 주의

Oracle 공개 페이지 사이에 A1 무료 한도가 다르게 표시된다.

- Always Free 안내: 모든 테넌시에 월 1,500 OCPU-hours와 9,000 GB-hours. Always Free 테넌시에서는 2 OCPU / 12 GB에 해당한다고 설명한다.
- Global Price List: A1 첫 월 3,000 OCPU-hours와 18,000 GB-hours를 무료로 표시한다. 가격표 PDF 표지 날짜는 2026-10-08.
- 두 자료의 문구 및 적용 조건이 완전히 일치하지 않으므로, 실제 계정에 적용되는 한도를 추측만으로 확정하지 말 것. PAYG 전환 후 OCI 비용 분석/사용량 화면에서 A1의 무료·과금 사용량을 확인하고, 첫 청구서도 대조할 것.
- 두 한도는 각각 누적 사용량으로 계산된다. 기존 A1 인스턴스가 있으면 사용량을 합산해야 한다.
- 단순 계산(730시간 기준): 3 OCPU·18 GB는 2,190 OCPU-hours와 13,140 GB-hours다. 3,000/18,000 한도라면 이론상 한도 이내지만, 1,500/9,000 한도라면 초과분 비용이 발생할 수 있다. 따라서 월 0원이라고 단정하지 말 것.
- 가격표 기준 메모: A1은 OCPU-hour와 GB-memory-hour 각각 별도 측정되며, 무료 구간 이후 단가는 지역/가격표에 따라 달라질 수 있다. 리소스 생성 직전 현재 리전의 OCI 가격표와 Estimate/Cost Analysis를 다시 확인할 것.

## 계정 업그레이드 화면에서 본 조건

- 화면은 사용량 기준(Usage-based)이며, 최소 기간 및 선결제는 없다고 안내함.
- 화면의 `월간 지출이 최대 수천 달러인 계정에 적용됩니다` 문구는 안내 문구이며, 그 금액을 최소로 지출하거나 약정해야 한다는 뜻은 아닌 것으로 읽힌다. 화면에는 실제 사용량에 따라 월별 비용 청구라고 명시되어 있음.
- 개인/법인 선택이 구분되어 있다. 사업자 등록 번호가 `필요`로 표시되는 항목이 법인 선택에 속하는지, 실제 개인 선택 상태에서 요구되는지 확인할 것. 공개 화면 설명만으로 개인 계정의 세무 입력 필드를 확정하지 말 것.
- 카드 검증은 업그레이드 전 카드 확인 단계이며, 화면은 업그레이드 실행 시 카드에 임시 승인이 표시되고 자동 취소될 수 있다고 안내함.

## 계약 문서 메모

사용자가 제공한 [Oracle Cloud Services Agreement – Singapore, Online v040119](https://www.oracle.com/a/ocom/docs/corporate/cloud-csa-sg-eng-v040119.pdf)는 2019-04-01판이다. 현재 가입 화면의 최신 주문/계약과 동일하다고 간주하지 말고, 실제 동의 직전 연결된 문서와 주문서를 확인한다. 이 계약서 제18조는 계약서와 참조 문서 및 주문서가 전체 계약을 이루며, 불일치가 있으면 주문서가 우선할 수 있다고 적는다.

이 문서에서 확인한 주요 항목:

1. **사용량 초과/요금:** 주문한 서비스 수량을 넘으면 초과분 비용을 지불해야 한다. 수천 달러의 지출 상한이나 자동 정지 약속은 이 계약서에서 찾지 못했다.
2. **서비스 제한:** 불법 사용, 허용 사용 정책 위반, 보안·가용성에 대한 중대한 위협이 있으면 Oracle이 접근을 일시 정지할 수 있다. 정지 기간에도 이미 발생한 요금 지급 의무는 남는다.
3. **금지 행위:** 불법 행위, 스팸, 암호화폐 채굴 등을 금지한다. 사전 서면 승인 없는 성능/취약점 검사 및 공개 벤치마크·가용성 테스트 제한도 포함한다.
4. **서비스 보증:** 오류 없음 또는 중단 없는 운영을 보증하지 않는다고 적혀 있다.
5. **책임 한도:** 일반적으로 문제를 일으킨 서비스에 대해 직전 12개월 동안 실제 지급한 금액을 Oracle의 총 책임 한도로 둔다.
6. **준거법:** 이 문서에서는 싱가포르 법과 싱가포르 법원의 전속 관할을 정한다. 현재 한국 계정의 실제 계약에 적용되는지는 최신 주문 문서를 확인해야 한다.

## 서비스 속도/운영 평판

- 사용자 커뮤니티에는 OCI 콘솔이 느리거나 타임아웃 난다는 글, 일부 리전에서 네트워크 지연/처리량이 낮다는 글이 있다. 이 사례만으로 전체 OCI 또는 서울 리전의 성능을 일반화할 수 없다.
- 원인은 콘솔/브라우저, 리전, ISP 경로(peering), shape의 네트워크 대역폭, 무료 자원 제한, 앱/DB 자체 병목 등으로 나뉠 수 있다.
- 실제 배포 후 서울/한국 모바일망 등 목표 사용자 환경에서 테스트하되, 계약서의 사전 승인 없는 공개 벤치마크 제한을 준수할 것.
- 무료 A1 한도 변경 및 서비스별 EOL 공지가 있었으므로 Always Free 제공량을 장기간 보장되는 전제로 설계하지 않는다. OCI 전체가 종료 중이라는 뜻은 아니다.
